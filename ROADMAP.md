# Roadmap and release gates

No stable release is declared by this setup. Complete and record these gates before a release:

- Review Linux ARM64 fixes for upstream submission.
- Exercise 4 KiB and 16 KiB page configurations.
- Check Android and Apple builds for regressions.

Each gate needs a reproducible test or a reviewable evidence record. GitHub issues track the work; the [GitHub Project](https://github.com/users/Connorbelez/projects/18) groups the backlog.
